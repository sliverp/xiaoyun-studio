# 安全与数据

这是一个有权访问模型、平台账号和推流目的地的单管理员服务。仅向可信操作者开放，适用于独立部署；不能当作公开匿名上传、多人共享算力的平台。多个直播场次共用同一管理员认证和上传素材库，所有已登录控制端都能查看、编辑和切换场次；按场保存不等于多租户或权限隔离。需要相互隔离的管理员或同时运行不同直播时，应部署独立服务和数据卷。

管理员登录凭据以 scrypt 保存，有错误登录限速；未指定密码时，首次随机密码另以明文写入权限 0600 的 `first-login.txt`，该文件也需保护。浏览器会话使用 HttpOnly、SameSite=Strict Cookie，存于服务内存，重启后需重新登录；修改操作检查来源。公网需配置 HTTPS 并启用 Secure Cookie。每个活动场次的渲染器使用独立只读令牌，只能读取节目与素材，不能修改配置或开始推流；切场后旧令牌失效。

模型、语音和推流密钥不在前端状态接口返回，只返回“是否已设置”；管理员可通过专门接口获取当前场次的弹幕接入密钥。私密凭据保存在权限 0600 的独立文件中，**没有应用级磁盘加密**。复制当前场次会复制已保存的模型、语音和推流密钥，副本生成新的弹幕接入密钥，不复制平台登录状态；复制前应确认副本的用途。具体范围见[场次说明](projects.md#新建复制与保存)。

私密请求错误经过脱敏。推流地址与密钥分开填写，FFmpeg 的完整进程参数可能被同宿主机具备进程读取权限的用户看到，因此不应与不可信用户共享主机。应保护整个持久数据目录、宿主机和备份，而不只是当前场次的设置文件。

HTML 演示稿会在隔离浏览器进程内执行 JavaScript；不要加载未知来源材料。默认拒绝本机、内网和云元数据地址，且渲染令牌仅附给本服务同源请求。此网络检查不是完整网络隔离，DNS 与浏览器网络栈仍有检查/使用时间差；处理不可信文件应同时通过容器网络或出站代理限制目标。生产镜像中的 Chromium 以禁用 sandbox 的容器配置运行，应保留容器边界并只加载可信材料。不要挂载 Docker socket、宿主机密钥或生产账号目录。

上传限制文件类型、大小、路径和符号链接逃逸；上传的 HTML 在控制浏览器直接下载，内部渲染器才内联加载。节目、素材、录像、报告、平台扫码截图和监听音频都要求登录。可选弹幕接入密钥按场生成，只允许写入弹幕/指标，不能读取状态或控制导播；接入请求按当前场次验证密钥，切换后需要使用目标场次的密钥。网页写操作携带场次 ID，服务端拒绝已过期的场次操作；这用于避免误写，不替代权限控制，接口说明见[场次接口](api.md#直播场次)。

独立的平台浏览器保留扫码会话，登录截图可包含账号信息，仅向已登录操作者提供。平台会话不随复制场次共享，但会保留在原场次目录中。使用者需遵守平台规则，获得账号与直播数据处理授权。开源仓库不包含真实会话和观众数据。

数据目录包含受保护内容，请勿提交 Git。音频缓存有数量清理；录像和事件历史会持续占用磁盘，需安排归档。删除非当前场次会删除其私有配置、凭据、历史与运行文件，不删除服务共享的上传素材；需要保留的内容应先导出备份。数据归属见[架构说明](architecture.md#数据归属)，升级、迁移和恢复前应备份整个数据目录并限制备份访问。本版本不提供审计签名或加密密钥托管。

多平台连接的浏览器资料位于 `STUDIO_DATA_DIR/projects/<场次ID>/platforms/<连接ID>/`。删除连接会关闭它自己的浏览器并清除该目录，不操作其他连接或用户桌面浏览器。采集只读取平台数据，页面点击仅限允许的登录/二维码控件，不提供评论发送、点赞、关注、购买或开播按钮的自动操作。平台适配器的正常网页子资源仍需出网，部署者应按平台要求管理网络和账号。
