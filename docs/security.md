# 安全与数据

这是一个有权访问模型、平台账号和推流目的地的单管理员服务。仅向可信操作者开放，适用于独立部署；不能当作公开匿名上传、多人共享算力的平台。

管理员密码以 scrypt 保存，有错误登录限速。浏览器会话使用 HttpOnly、SameSite=Strict Cookie；修改操作检查来源。公网需配置 HTTPS 并启用 Secure Cookie。渲染器使用单独只读令牌，只能读取节目与素材，不能修改配置或开始推流。

API Key 和推流密钥不在前端状态接口返回，只返回“是否已设置”。它们保存在权限 0600 的独立文件中，**没有应用级磁盘加密**；应保护数据卷、宿主机和备份。私密请求错误经过脱敏。推流地址与密钥分开填写，FFmpeg 的完整进程参数可能被同宿主机具备进程读取权限的用户看到，因此不应与不可信用户共享主机。

HTML 演示稿会在隔离浏览器进程内执行 JavaScript；不要加载未知来源材料。默认拒绝本机、内网和云元数据地址，且渲染令牌仅附给本服务同源请求。此网络检查不是完整网络隔离，DNS 与浏览器网络栈仍有检查/使用时间差；处理不可信文件应同时通过容器网络或出站代理限制目标。生产镜像中的 Chromium 以禁用 sandbox 的容器配置运行，应保留容器边界并只加载可信材料。不要挂载 Docker socket、宿主机密钥或生产账号目录。

上传限制文件类型、大小、路径和符号链接逃逸；上传的 HTML 在控制浏览器直接下载，内部渲染器才内联加载。节目、素材、录像、报告、视频号扫码截图和监听音频都要求登录。可选弹幕接入密钥只允许写入弹幕/指标，不能读取状态或控制导播。

独立视频号浏览器保留扫码会话，登录截图可包含账号信息，仅向已登录操作者提供。采集只读取后台响应，不发送评论或操作平台开播。使用者需遵守平台规则，获得账号与直播数据处理授权。开源仓库不包含真实会话和观众数据。

数据目录包含受保护内容，请勿提交 Git。音频缓存有数量清理；录像和事件历史会持续占用磁盘，需安排归档。备份应有相同访问控制。没有内置多租户隔离、角色权限、审计签名或加密密钥托管；需要这些能力时应在部署架构中补齐。


多平台连接分别保存在数据目录的 platforms/<connectionId> 中。删除连接会关闭它自己的浏览器并清除该目录；不会操作其他连接或用户桌面浏览器。私密平台截图要求管理员登录，页面点击仅限允许的登录/二维码控件；不提供平台评论发送、点赞、关注、购买或开播按钮的自动操作。平台适配器的正常网页子资源仍需出网，部署者应按平台要求管理网络和账号。
