# 直播场景与直播场次

场景保存可复用的配置；场次保存一次实际开播的过程与数据。一个场景可以连续开很多场，不需要每次复制设置。

## 新建、复制与保存场景

登录后进入「直播场景」列表。点击「新建场景」准备空白配置，或「复制当前场景」沿用已有设置。创建后留在列表，点「打开场景」进入工作台；顶部显示当前场景名称。

场景包括主播人格、音色、口播、演示稿与笔记、画面布局、节目规则、平台连接和服务凭证。统一通过「保存场景设置」保存，平台连接在弹窗内单独保存。空白场景没有演示稿、口播和平台连接，秒杀与抽奖默认关闭。

复制保留配置、私有凭证和被引用的生成音频，生成新的弹幕接入密钥；不复制直播场次、中奖历史、奖品消耗、录像、浏览器登录和其他运行记录。新场景需重新扫码登录。

## 每次开播形成独立场次

在「直播控制」开始推流或录制，至少一个发送端或录像端出现实际输出进度后自动生成新场次。仅准备输出、预览、试听、启动 AI 或连接弹幕都不会生成场次。只有本地录像时明确标为「本地录制」。

重连、暂停 AI、刷新控制页和打开场景列表仍属于同一场；全部输出停止后结束该场，再次成功启动输出形成下一场。「结束本场直播」同时停止本服务输出与 AI。不同平台逐个加入同一场，不会为每个平台另建场。

使用直播姬等外部软件开播时，点击「记录外部开播」开始计时，在下播后点击「结束本场直播」。这是手动记录，不会替代外部软件的开播/下播。手动场次中，本服务的输出停止不会自动结束外部直播记录。

## 回看实际数据

打开工作台「直播场次」，选择一场直播查看：

- 开始时间、结束时间、状态、结束原因和时长。
- 各平台已采集的最高在线、累计观看人数、点赞和弹幕数。
- 分页保存的弹幕、人数/互动指标、AI 口播、抽奖和输出状态事件。
- 本场录像链接与 JSON 导出。

弹幕只统计本次开播期间收到并通过校验、去重的数据。人数无法采集时显示「未采集」，不补零；不同平台不相加、不推算去重观看人数。平台累计观看人数保留原始口径，不能当作从本地计时开始推算的新增人数。指标事件保留采样来源与时间。

结束的记录刷新或重启后仍可查看。服务异常退出时，旧场次标为「已中断」，以最后检查点或完整事件时间结束，不把停机时间计入直播时长。升级前的日志保留原样，不猜测拆分成场次。

## 返回列表与切换场景

返回「直播场景」会立即关闭本浏览器的声音监听和麦克风，后台直播与录制继续运行。重新打开场景不会自动恢复监听，可点击「本机声音」或发起播报。

切换到其他场景前，未保存的设置可选择保存、放弃或取消。当前正在播报、推流、录制或手动记录场次时，需要明确确认结束后切换；旧场归档，所选场景保持停止。另一设备切换后，本页同步到新场景，旧操作不会覆盖新场景配置。

当前场景不能删除。删除非当前场景会删除其配置、凭证、登录目录、全部场次和私有运行文件；共享上传素材不受影响。需要保留的录像或场次先导出备份。

## 首次升级与数据位置

原有可保存配置统一改称「场景」，ID、配置、凭证和登录目录保留；旧版第一次引入多配置时复制到「原配置」的迁移逻辑保持不变。

管理员凭据、场景清单 `projects.json` 和上传素材位于数据根目录。场景资料在 `projects/<场景ID>/`，新场次资料位于其下 `broadcasts/<场次ID>/session.json` 和 `events.ndjson`，索引为 `broadcasts/index.json`。录像仍由所属场景的 recordings 目录保存。

同一服务同时运行一个当前场景，共享管理员认证与素材库。完整备份应包含整个持久数据目录，包括所有场景、场次、凭证、平台会话和素材。
