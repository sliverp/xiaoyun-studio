# 从旧项目导入

本仓库是独立服务，不是原有安装的覆盖升级。迁移命令只读取旧项目文件，将允许的演示稿和已校验录音复制到本仓库的数据目录；不会改动旧服务、账号、浏览器窗口、OBS、配置文件或已有运行流程。

```sh
npm run migrate -- --source /path/to/previous-project
```

默认复制旧项目 `materials/live-1024-deck/site` 中的演示资源、合并笔记、口播文案和 stage-audio 清单中通过 SHA-256 校验的音频。导入结果可在新导播台素材库选择；默认不切换当前素材。给命令增加 `--apply` 才将新服务的演示地址、笔记、系统话术和固定口播更新为导入结果。

原项目中的密钥、浏览器配置、平台登录、观众信息、历史录像和开播状态都不导入。配置新服务所需账号时重新填写，避免两个系统误共享运行状态。新系统只会在管理员点击开始后运行。

默认数据目录是 `.data`，可用 `--data /new/data/path` 改写；程序拒绝写入旧项目内部。导入文件处于 Git 忽略目录，不会跟随开源仓库发布。

公开演示素材只包含仓库内注明来源的人物、BGM 和示例口播。部署者可通过上传与配置替换。PPTX 不直接解析；请转换为 HTML 或 PDF。
